# Изменения sib-monitor

Формат раздела: `## <версия> — <дата выкладки ГГГГ-ММ-ДД, МСК>`, подразделы
`### Улучшения`, `### Исправлено`, `### Прочее`. Пишется для пользователей, без внутренней
кухни. Из этого файла собирается ежедневная сводка в Telegram (23:30 МСК). Новые релизы
добавляются сверху.

## 2026.11.08-monitor.11 — 2026-11-08
### Улучшения
- Ежедневная сводка изменений в Telegram в 23:30 МСК — только в дни, когда были релизы.
- Раздел «📖 Описание функционала» в админке дополнен архитектурой (HLD), схемой развёртывания, диаграммами C4 и подробным описанием работы.
### Исправлено
- При недоступной базе данных приложение могло перестать отвечать (ошибка 502); теперь подключение ограничено по времени, а проверка /health не блокирует остальные запросы.

## 2026.11.08-monitor.10 — 2026-11-08
### Улучшения
- Если срок SSL определить не удалось, рядом с «—» показывается значок ⓘ с причиной.
- Сайты без данных SSL проверяются повторно через 15 минут, а не через 4 часа; последний известный срок не стирается.
### Прочее
- Резервная внешняя проверка SSL используется только при сетевой недоступности сайта; ошибка сертификата остаётся ошибкой.
- Таймаут подключения SSL-проверки увеличен с 3 до 8 секунд.
- Введены обязательные проверки качества перед релизом и контроль после выкладки.

## 2026.11.08-monitor.9 — 2026-11-08
### Улучшения
- Сертификаты корпоративного удостоверяющего центра (например, SiburInfrastructureCAG1) обрабатываются как самоподписанные: сайт Online с пометкой 🔓.
- Срок SSL определяется и для сайтов, недоступных из сети монитора.
### Исправлено
- cp.tdms.sibur.ru/cp/ показывался как «TLS Error» при действующем корпоративном сертификате.

## 2026.11.06-monitor.8 — 2026-11-08
### Улучшения
- Сайты с самоподписанным сертификатом проверяются и не считаются ошибкой при действующем сроке и верном имени; в строке сайта пометка «🔓 самоподписанный сертификат».
- Неполная цепочка сертификата достраивается автоматически, как в браузере.
### Исправлено
- В сообщении о восстановлении писалось «Был недоступен: 0 мин.» — теперь указывается реальное время простоя.
- Действующие сертификаты sibur.ru, shop.sibur.ru, greencity-sibur.ru, rusvinyl.ru ошибочно отмечались как ошибка TLS.
